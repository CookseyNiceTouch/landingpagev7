# Press kit assets

This folder is served at `/press/` on the live site. The web page at
[nicetouch.app/press](https://nicetouch.app/press) reads structured copy from
[`src/data/press.ts`](../../src/data/press.ts) and links to the binary files
inside `public/press/assets/`.

## Rebuild the ZIP

After dropping in or updating any asset under `assets/`:

```bash
npm run press:zip
```

The script wraps everything under `assets/` into `nice-touch-press-kit.zip`
in this folder.

## After uploading assets

1. In `src/data/press.ts`, set `available: true` on each gallery entry whose
   file you've just uploaded.
2. For founder/investor headshots, set the `headshot` field on the
   corresponding entry in `FOUNDERS` / `INVESTORS` to the file path (the
   commented-out path above each entry is the expected one).
3. Run `npm run press:zip` to refresh the ZIP.
4. Commit the new files **and** the regenerated ZIP.
