# Nice Touch Landing Page V8

A modern landing page for **Nice Touch** – an always-available video editing assistant that works with Adobe Premiere Pro and DaVinci Resolve.

Built with React 19, TypeScript, and Vite.

---

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

---

## Tech Stack

- **React 19** + TypeScript
- **Vite 7** for fast dev & builds
- Pure CSS styling (no Tailwind)
- Fully responsive (desktop, tablet, mobile)

---

## Project Structure

```
src/
├── App.tsx        # Main layout (header + hero)
├── App.css        # Component styles + responsive breakpoints
├── index.css      # Global styles & CSS variables
├── main.tsx       # React entry point
└── assets/        # Local assets (if any)
```

---

## Features

- Gradient text hero title
- Video media panel with play overlay
- Social media links (LinkedIn, YouTube, Discord)
- App badges (Premiere Pro, DaVinci Resolve)
- Fully responsive from 1920px down to 320px
